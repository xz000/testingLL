## 二、游戏模式（`En`）

`En` 取 1–5（**无 En==6**），在设置菜单里以中文显示：

| En | 名称 | 说明（实证） |
|---|---|---|
| 1 | **回合** | 打满设定位数；`-`+总回合数 开始。`En==1` 出现在 8 处（回合计数/胜负判定） |
| 2 | **死亡竞赛** | `-`+胜利得分 开始；`En==2` 11 处 |
| 3 | **化身** | 玩家变成"化身"单位（`SetUnitScale(Nr,1.4,1.4,1.4)` 在多处对 `En==3` 生效）；`En==3` 16 处（最多） |
| 4 | **弑君** | 存在"国王"单位：击杀判定 `RI==JV or RI==kV` → 广播 `|cffdaa520国王|r被击杀了!` |
| 5 | **生存** | 刺客/复活机制：生成 `'dead'` 尸体单位 `dV[]`、文本标签 `CV[]`、刺客归属 `DV[]`；`En==5` 8 处 |

胜负：`yd and not OV` → `ExecuteFunc("eI")`（某队全灭则结束）；结束后 `Ln[dn]++`（队伍得分）并 `zR()`。

## 四、核心循环

1. **开局购物**（`Wo` 秒）→ 用 `So` 金钱买技能/属性/物品。
2. **战斗**：实时对战，玩家施法、走位、抢柱子。
3. **购物阶段**（每轮 `wo`=30 秒）→ 再次购买。
4. **击杀/复活**：
   - 击杀者 +`mo` 金 +`lo` 分；助攻者 +`Mo` 金 +`Lo` 分。
   - 连杀播报 `Mn[3..10]`：大杀特杀(3) / 主宰比赛(4) / 迈向胜利(5) / 狂暴了(6) / 无法阻挡(7) / 变态了(8) / 接近神了(9) / 超越神了(10)，配 `mn[]` 音效。
   - 死亡：隐藏英雄 `ShowUnit(Xn,false)`、建 `'dead'` 尸体单位 + 文本标签 `CV[]`、
     `kO(function VI, to+GetRandomReal(-.5,.5), …)` 定时复活。
     **复活基础时长 `to=10` 秒**（全局声明 `integer to=$A`），实际 `10±0.5s` 随机。
   - 复活位置（`function VI`）：自定义布局 `la` 为真时从预设点 `BV[]`（共 `cV` 个）随机取点 + ±128(`$80`) 抖动；
     否则在 `±ua*64` 的方形内随机。复活前置 `Bn[id]=true`。

## 五、场地 / 地形 / 柱子

- **场地形状**：`Ua`（0=圆 CIRCLE / 1=方 SQUARE）、`Ma`（是否环形 donut）、`la`（自定义 CUSTOM）。
- **柱子**：`Qo`（0=随机）。
- **熔岩地形**：`sa[ka]` / `Sa[ka]` 为地形类型码；踩上去每秒受 `Uo[]*10`（默认 0.9×10=9）伤害。
  多个技能对"是否在熔岩上"有判定：
  - 天罚 `KC` / 虔诚 `pC`：站熔岩 + `aV[]` → 走 `HC()` 特殊分支。
  - 瞬间移动 `hB` / 移形换位 `lB`：从熔岩移到安全处且残血 → 触发 **"死里逃生"** 文字+音效。
- **场地周期**：`yo`=15（每玩家），即随人数变化的场地轮换。

## 七、投射物 / 碰撞引擎（移植核心）

098b 是**自己实现的弹道系统**（不用 WC3 原生导弹），这是移植时最需要复刻的部分。

| 函数 | 作用 |
|---|---|
| `eO(id)` | 从空闲链表分配一个投射物 id |
| `VO(kind,player,unitType,x,y,facing,model)` | 生成投射物假人单位 |
| `IO(id,speed,tx,ty)` / `bO(...)` | 设置速度（朝目标点） |
| `xO(id,boolean)` | 销毁投射物 |
| `kO(code,time,args...)` | 计时器（几乎所有 buff/debuff/延时都用它） |
| `Nb(...)` | 生成闪电光束（闪电 S002、锁链 S019 用） |

**碰撞判定**：投射物把命中回调存成 `boolexpr` 放进 `hv[id]`，引擎执行
`TriggerAddCondition(Ge,hv[id]); TriggerEvaluate(Ge)`。
`hv[]` 里存的是**预先绑定的全局**（68 个，形如 `set Va=Condition(function NC)`），
所以要看某个技能的命中效果，必须查"全局→真实函数"映射（见 `jass_deobf.md` §七 与 `abilities_control_098b.md` 附录）。

**迭代周期 = 0.03 秒**：源码中速度一律写成 `速度*0.03`（共 71 处），如
`set Q[Ib]=900*.03*TX/Ar`。即每 tick 位移 = 速度×0.03，约 33.3 次/秒。

**关键引擎常量**（全局声明块实证）：

| 常量 | 表达式 | 值 | 用途 |
|---|---|---|---|
| `Hr` | `$514*.03` = 1300×0.03 | **39**/tick = 1300 单位/秒 | 冲撞/冲刺速度（`Q=Hr*dir`） |
| `jr` | `Hr*(1-.96)` | 1.56 | 冲刺的衰减速度（`U=jr*dir`） |
| `Co` | `$D2*.03` = 210×0.03 | 6.3/tick = 210 单位/秒 | 通用速度常量 |
| `do` | `Co/20` | 0.315 | — |
| `wn` | constant | 9 | `Dn[i]=-wn` |
| `jo` | — | 64 | 复活范围 `±ua*64` |
| `Ho`/`mr` | `-$80` | -128 | 坐标偏移（复活抖动 ±128） |
| `Mr` / `Lr` / `Dr` / `Fr` | — | 75 / 70 / 29 / 200 | 各技能半径类常量 |
| `pr` | `'d'` | 100 | 锁链升级给自身的移速加成 `DR(ni,+pr)` |
| `Jo`/`ko`/`Ko` | `'h000'`/`'h003'`/`'u000'` | — | 术士英雄A / 术士英雄B / 商店 单位类型 |

（旁证：`Hr=1300*0.03=39` 与 CE 的 `ThrustVel` 完全一致，说明两版本共用同一套弹道手感。）

**投射物存活时间**用 `ev[id]`（"时间预算"），如 引力漩涡 `ev=5*jn`。

## 八、伤害管线

```
命中 → KI(施法者,目标,base,mult) 或 jI(...)
     → kI = 100 * gX * JI * 0.03          // 基础换算
     → × Gn[攻击方]   伤害倍率（默认 1）
     → × hn[防守方]   受伤倍率（默认 1）
     → × Hn[]         击退/体形缩放（默认 1）
     → 减免判定
     → FI() 扣血 / 飘字 / 统计 / 击杀
```

- **特殊减免**：`rx[目标]==985` → 伤害 ×0.8；`rx==954` → ×0.4。
- **无敌**：`Dv[]` 为真 → 伤害 0。
- **法力相关**：`fv[]` → 按法力缩放。
- **法强系数**：`eb(id)=1-0.1*max(0, 智力-(力量+敏捷+体质))`，公式里常写成 `1.1*eb(...)`。
- **AoE 链**：`qI → PI → LI`，`LI` 施加 `gX*(pI+(1-pI)*NO)` 距离衰减，半径 `pe*(1+0.12*ri)`。
- **持续时间**：全部乘 `jn[玩家]`（默认 1）——改 `jn` 可整体缩放所有 buff/debuff。

## 十一、移植注意事项（以 098b 为准）

1. **弹道必须自己实现**：098b 完全自绘（`amcs`=0、弹道是假人单位），不能依赖引擎原生弹道。
   复刻顺序：`eO` 分配 → `VO` 生成 → `IO/bO` 速度 → 每 tick 位移（×0.03）→ `hv[]` 命中回调 → `xO` 销毁。
2. **命中回调是间接的**：`hv[id]` 存 boolexpr 全局，先查映射表再读函数，否则会漏掉真实伤害/控制逻辑。
3. **数值分裂在两处**：静态平衡（名字/CD/距离/等级/耗蓝/AoE `aare`）在物体数据；
   动态（伤害公式/击退/持续时间/impact）在 JASS。**两边都要取**，只看一边会漏。
4. **tooltip 只是参考**：其 CD≈技能 1 级值，持续/伤害是静态近似，与真实表达式有偏差
   （见 `abilities_calibration_098b.md`）。
5. **CE 不能当数值源**：两版本 28 个技能里 21 个字段不同；英雄魔法上限 10000 vs 200 这种量级差异，
   照抄 CE 会完全跑偏。CE 的价值是**机制参照**（其 JASS 明文可读），不是数值。
6. **已核准**：复活时长 `to=10`、开局购物 `Wo=40`、`wn=9`（constant）——均已从全局声明块钉死。
   仍**未核准**的少量项：`do`/`Do=30`/`fo=60`/`go=35`/`ar=1246`/`nr=1353` 的具体归属调用点，
   以及 `la`（自定义布局）的开关来源——需要时再到 `war3map.j.dec` 里按常量名搜引用。
