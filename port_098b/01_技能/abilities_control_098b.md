# 098b_CN 控制 / 辅助技能 —— 真实机制解码

> 配套文件：`abilities_consolidated_098b.md`（逐法术总表，含 CD/名字/距离/耗蓝）
> 配套文件：`abilities_detailed_098b.md`（弹道模型 / 伤害公式 / impact 绑定表）
>
> **重要修正**：上一版总表里我把 S001/S002/S020/S021 以及多数控制技标成
> "（控制/位移/无直接伤害）"——这是**错的**。实际解码后发现：
> - **天罚 / 闪电 / 灾变** 都**直接打伤害**（AoE nova / 闪电链 / 逐级强化终极）。
> - **虔诚** 是**治疗+伤害双效光环**（打敌+奶友）。
> - 真正的"纯控制/位移"只有：反射盾、时光回溯、急行、瞬间移动、冲撞、移形换位、
>   火焰喷射、致残、引力、锁链、S031 链锁附加。
>
> 解码方法：每个 handler 里 `set hv[Ib]=<全局>` 存的是**预先绑定好的 boolexpr 全局**
> （共 68 个，形如 `set Va=Condition(function NC)`）。所以要先查"全局→真实函数"映射，
> 再读那个函数体。映射表见文末 §附录。

## S001 天罚（handler `KC`）—— 近身 AoE nova（有伤害！）

循环所有单位 `dX=Kv`；对每个**敌对方**单位：
- 距离 `NO=uX(dX,ni)`，若 `NO<=$FA`(250)，`KI(ni,dX,DX,1-NO/$3E8)` —— 随距离衰减的 AoE 伤害。
- `DX`：`ei[ai]==0` 时为 `$A`；否则 `$B+ei[ai]`（手杖 ei 加成），并播放右手特效。
- 若目标被锁链绑定 `Fv[dX]==ni` 且位于特殊地形/相位 → 触发 `oR(dX)` 并弹"否决"字样。
- `ei[ai]==2` 时每命中 1 个扣 4 蓝（`-4*n`）。
- 命中 ≥3 个：弹"帽子戏法"（普通）/ "吸血鬼"（lC 吸血鬼标志开启）并播放音效。
- `rV[17+24*ai]`（某购买标志）且 `Ja[ai]`：转而调用 `gC` 进入特殊分支。

**机制**：以自身为中心、半径 250 的瞬时 AoE 爆发，打所有附近敌人（非纯控制）。

## S002 闪电（handler `hb`）—— 闪电链光束（有伤害！）

- 计算施法者→鼠标方向单位向量。
- 射程 `Bb=(1+0.15*oi[ai])*600`（随升级 oi 增长）。
- 伤害 `DX=(6+1*Wr[ai])`（随等级 Wr 增长）。
- `Nb(bb,px,py,dx,dy,Bb,DX)` 生成一道闪电，沿光束长度造成伤害（用 KI 类的伤害核心）。

**机制**：瞬发闪电光束，伤害 `6+等级`，射程约 600–900。

## S005 反射盾（handler `DC`）—— 反弹护盾（纯控制）

- 若 `Qr[ni]==0`（无盾）：`eO(3)` 生成一个"假人弹体"绑定施法者，`hv=dX`→`va=CC`（反弹 impact），
  `jv=dX`→`ea=dC`（护盾跟随 impact），`Fv[dX]=ni`，`cv[dX]=2`。
- 持续 `(2.6+0.2*vi[ai])*jn[ai]`，头顶显示 MagicSentry 特效。
- 若已有盾：立即 `$D0004` 取消。

**反弹命中（`CC`=va）**：算弹体→盾方向，若目标 `Ev==9 / Ea / (nv==1 且非 Jr)` 则**不反弹**（return），
否则把来袭弹体沿原方向反射回去。

**护盾跟随（`dC`=ea）**：把护盾假人坐标同步到施法者 `K/L/Q/S`。

**机制**：一段时间内反弹所有打中你的弹体（纯防御/控制）。

## S006 时光回溯（handler `fC`）—— 延时回溯（纯位移/控制）

- `XR=ni+500`：建一个"幽灵单位" `F[XR]`（类型 `'thrd'`），把施法者当前
  `K/L/Q/S/U/w/Y/z/G/ev/Jr` 全部拷进幽灵。
- 记一个 `le[ni]=kO(function ER, 3.6*jn[ai], ni, XR, 当前HP, 当前MP, 朝向)`。
- 若 `le[ni]!=0`（已在回溯中）则拒绝并取消。

**回溯执行（`ER`）**：延迟后把施法者**瞬移回幽灵记录的位置/状态**（`K/L/Q/S/U/w/Y/z/G/ev/Jr` 还原），
并 `oR(ni)` 清链。若 `Jr[ni]`（冲撞相位）则重新挂 `hv=Ei`。

**机制**："标记当前位置，3.6×jn 秒后闪回该处"（位移/保命技）。

## S012 冲撞（handler `wB` 升级版 / `IB` 非升级版）—— 冲撞击退（控制+伤害）

  移动指令 → `uB` 触发挥击击退 `IO(ni,20,TX,TY)`。

**机制**：朝目标冲刺，命中造成伤害+击退（升级版是"相位状态，移动即冲"）。

## S017 致残（handler `bC` 升级版 / `eC` 非升级版）—— 残废（控制+小AoE）

**机制**：给目标上残废 debuff；升级版是双链弹，非升级版带小范围 AoE。

## S019 锁链（handler `Tc` 升级版 / `tc` 非升级版）—— 锁链拉拽（控制）

## S020 灾变（handler `MC`）—— 逐级强化的终极 AoE（有伤害！）

结构与天罚 KC 极像，但**三级递进**：
- `Ur`：0→1→2，每放一次 `Ur+1`（到 3 后循环）。
- 伤害 `DX`：`Ur==0`→`$B`，`==1`→`$C`，`==2`→`$E`（递增）。
- 作用半径：`Ur==0/1`→300，`Ur==2`→400。
- 命中后 `n>0`：`DR(ni, FR+50)` 加 50 移速，并挂 PhoenixMissile 特效（脚/胸，最多 3 段）。
- 对绑定目标触发 `oR` "否决"；≥5 命中弹"帽子戏法"/"吸血鬼"。
- 每级之间有 6×jn 秒冷却（`TimerStart(Tr,6*jn,...,LC)`）。

**机制**：越放越强的 AoE nova 终极技（非纯控制）。

## S021 虔诚（handler `pC`）—— 治疗+伤害双效光环（有伤害+治疗！）

**机制**：以自身为中心，打敌(250) + 奶友(500) 的双效光环（非纯控制）。

## S031 锁链附加动作（handler `oR` / `Pc`）—— 链锁收尾

- **`oR`（被 KC/MC/Tc/tc 调用）**：`rR=Fv[dX]`（被锁目标）。
  - `nv[rR]==1/3`：销毁链光 `DestroyLightning(H[dX])`；
  - `nv[rR]==2`：`xO(rR,true)` 移除单位；
  - 复位：`S031` 关、`S019` 开、`Fv[dX]=0`。
- **`Pc`（S031 自身 handler）**：`jO(true,dX,true,$56A,...)` + `kO(function pc, 3*jn[Vv], dX, $56A,...)`；
  `pc` 再调 `oR(Yv)`。即把被链目标**眩晕/定身 `$56A` 持续 3×jn 秒**。

**机制**：锁链拉拽后的追加动作（定身被拉目标）。
