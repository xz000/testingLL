# 098b_CN 逐法术持续时间常量（JASS 计时器）

> 来源：`ce_old98b/war3map.j.dec` 中的 `kO(function X, time, …)` 与 `TimerStart(t, time, …)` 调用。
> 约定：`jn[ai]` / `jn[id]` 是**按玩家缩放的时间倍率**（默认 1，可被全局设置改），所以几乎所有持续时间都写成 `N*jn[…]`。
> 与 `abilities_tooltips_098b.md` 里写的"持续 X 秒"对照：tooltip 是静态近似值，下表是代码里的真实表达式。

## 二、伤害型法术的"灼烧/持续" DoT 时长

| 法术 | impact | 持续时间表达式 | 说明 |
|---|---|---|---|
| S000 火球（点燃） | `xc` | `(6+1.5*Xv[Er]+xi[Vv[Er]])*jn[Vv[Er]]*jn[Vv[Xr]]` | 灼烧 DoT：基础 6s + 1.5×等级 + xi，再 ×双 jn |
| S008 陨石（灼烧） | `nB` (=`Ba`→`nB`) | `4*jn[Vv[Xr]]` | 落点灼烧 4×jn 秒 |
| S010 疾风步破隐一击 | `Kb` | `4*jn[Vv[Xr]]` | 破隐一击附带的 4×jn 持续效果 |
| 其它弹道类 | `nB`/`ZB`/`QB`/`xc`/`Kb` | `4×jn` 或 `vc×jn` 等 | 各种溅射/持续由对应 impact 控制 |

> 注：`*jn[Vv[Xr]]*jn[Vv[Er]]` 这种**双 jn 相乘**是火球点燃的特色——同时被施法者与目标的时间倍率缩放。

## 三、关键结论

1. **所有持续时间都按 `jn[玩家]` 缩放**：这应该就是地图设置里的"游戏速度/持续时间"系数，默认 1。改 `jn` 就能整体拉长/缩短所有 buff/debuff。
2. **tooltip 的"持续"是静态近似**：真正长度由代码表达式决定，且常随技能等级（致残 +0.25/级、火球 +1.5/级）或升级等级 vi（反射盾/急行）增长。
3. **瞬时法术**（天罚/闪电/瞬移/换位）没有持续时间——它们是一次结算的 AoE/位移。
4. 控制技里**真正有"硬控制时长"**的是：致残定身 `(4+0.25×级)×jn`、锁链升级勾取 `4.5×jn`、冲撞命中 `0.5s` 定身、引力漩涡 `5×jn`、反射盾 `(2.6+0.2vi)×jn`。

## 四、复现方法
`kO`/`TimerStart` 抓取脚本（思路）：在 `war3map.j.dec` 中按 `function NAME takes nothing returns …` 切分函数体，
对每个函数体用正则 `kO\s*\(\s*([^,]+?)\s*,\s*([^,]+?)\s*,` 取第 2 个参数（时间），筛出含 `jn` 的即为持续时间。
