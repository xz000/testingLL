## A 类：基准冲突（需要拍板——098c 与 098b 机制本质不同）

### A1 · 魔法系统（最大差异，推翻 D3 的部分依据）

| | 098b（我们的依据） | 098c（解包实证） |
|---|---|---|
| 出生魔法 | 10000（恒满） | **0**（`fX`: 魔法=0, HP=满） |
| 魔法来源 | 无（无回蓝） | **挨打回魔**：`dX(目标,dmg)` 魔法 += 受到伤害 |
| 魔法用途 | 击退公式常数项 | 击退公式 **活变量**：`(100+魔法)` 从 100 → 最高 10100（**约 100 倍**） |
| 技能耗蓝 | 无 | **也无**（amcs 全 0；"消耗"=冷却+状态限制） |
| 定位 | 惰性池 | **核心张力**：魔法=资源兼"负重"，残血+满魔会被一击推飞 |

- 量化：HP 池 100、魔法池 10000 → 打掉 10 HP ≈ 目标获得 10 魔法（击退公式 +10/10100）。
- **我们的现状**：D3 删除了蓝量，`DAMAGE_BASE=303` 折叠固定值。098c 口径下这是错的——
  击退初速应是 `(100+目标魔法)×伤×Gn×hn×0.03×Hn×JI`，其中魔法逐击变化。
- 附加：TimeShift 回溯时魔法重算 `(0.8-zr/10)×(gn-ee)+ee`（zr=怀表等级）。

### A2 · 移动模型（文档原话"Warlock 的灵魂"）

| | 我们的实现（098b 口径） | 098c |
|---|---|---|
| 模型 | 加速度 1312.5 / 减速度 2625 直插满速 | **冲量滑行**：每次右键 `速度 += 18 × 0.5^(当前速度/20) × 方向` |
| 手感 | 匀速走位 | 低速加速猛、高速衰减 → 惯性滑行 |
| 帧积分 | `pos += vel×dt` | 同（0.03s/帧） |

### A3 · 物理碰撞

| | 我们的实现 | 098c |
|---|---|---|
| 碰撞检测 | 离散（帧内重叠后分离） | **扫掠连续**（t∈[0,1] 求交，防高速穿透） |
| 实体互碰 | 位置分离推挤 | **动量交换**（质量 dv=0.5，`(dv[a]+dv[b]+2)/4` 系数） |
| 撞墙 | 钳制+出界熔岩 | **反弹** `vel = -vel×0.5`（弹性 xv=0.5）+ 位置钳制 |

### A4 · 伤害倍率成长（W 系翻盘机制，098c 独有）

- 命中敌人 `Gn[施法者] ×= 1.1`（连乘）；部分技能 ×2/×10/×0.1；**死亡清零**；
- 头顶显示伤害点数；默认 Gn=1.0。
- 我们的现状：`gn_factor()` 仅灼烧 debuff 用（×0.1），无成长机制。

### A5 · 计分

| | 我们（098b ed()） | 098c |
|---|---|---|
| 轮胜利 | +1 | **+2** |
| 击杀 | +1 | **+2** |
| 助攻 | +1 | +1（按 Jn 伤害占比判定） |

### A6 · 生命回复

- 098c：单位 `uhpr=0`，**回复全靠物品/技能**（无基础回血）。
- 我们：`hp_regen=0.05`（098b zd() 的 Nn 口径）。

### A7 · 尺寸/半径细差

| 项 | 098c | 我们 | 差 |
|---|---|---|---|
| 术士碰撞 | `do=30` | 32 | 微 |
| 柱子半径 | `fo=35` 固定 | 24–40 随机 | 微（随机波动是用户认可的改良） |
| 弹体半径 | 44 | 火 25/追 29/回 40/陨 72 | 大（098c 统一 44？待核 per-spell） |
| 竞技场 | 约 [-4096,4096]（8192 宽，墙由 wpm 定） | 半径 640（用户体感） | 尺度体系不同，不能直接换算 |
| 死亡阈值 | HP < 0.5 | HP ≤ 0 | 微 |

### A8 · 岩浆伤害成长

- 098c：`To[0]×10` 每跳，**To[0] 随回合数成长** → 拖延越久岩浆越痛。
- 我们：固定 9/s。

## C 类：已确认一致（无需动作）

- 技能无原生耗蓝（amcs 全 0）——D3"无蓝量消耗"正确（但魔法系统 A1 另论）；
- 热键布局 G/D/E/R/T/Y/C/F；槽位语义（G=普攻、Y=终极、C=防御、F=特殊）；
- 多数 CD（火球 4.8、闪电 16.5→12.5、瞬移 16→11.5、TimeShift 3.6s 等）；
- 物品家族/效果（靴/盔/斗篷/坠饰/面具 24% 吸血/熔岩靴/怀表/乔丹之石）；
- 伤害矩阵 → 助攻（我们已实现同构 Jn 思路）；
-乔丹之石（学终极/破上限）概念。

7. **A7/A8**：柱子可摧毁（HP40+Shard）、岩浆随回合成长——小增量，建议做。
