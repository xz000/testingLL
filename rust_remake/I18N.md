# 多语言（i18n）

> 主语言：**简体中文**；当前支持：**简体中文 / English**。
> 语言由 **Steam 语言设置**驱动，也可在游戏内「设置」里手动覆盖。

## 一、快速了解

- 代码位置：`client/src/i18n.rs`（词条表 + 语言解析）。
- 以**中文原文为 key** 查英文表，好处：
  - 中文路径**零改动**（`t("中文")` 原样返回）；
  - **漏翻不会空白**（查不到回退中文，界面永远可读）；
  - key 即文案，中文改动后英文表一眼能看出是否过期。
- **不依赖任何新 crate**（client 一向不引 serde；词条是 Rust 静态表 + `OnceLock<HashMap>`）。

## 二、语言来源与优先级

```
LangPref::Auto（默认） ── Steam 游戏语言（Apps::current_game_language） ──┐
                                                                        ├─→ 实际语言
LangPref::Fixed(lang) ── 手动固定，无视 Steam ───────────────────────────┘
```

- `Auto` 无 Steam 会话时回退中文。
- 手动固定（如「简体中文」）**不会被 Steam 刷回去**——避免 Steam 客户端是英文、
  但玩家想要中文时每次启动都被改回英文。
- 读取时机：主菜单每帧 `Game::steam_ensure_session()` 之后调 `Game::steam_sync_language()`
  （见 `client/src/steam.rs`）；读 `SteamTransport::current_game_language()`（`net-steam`）。
- 持久化：`LocalSettings.lang`（`%APPDATA%/warlock_brawl/settings.txt` 的 `lang=auto|zh|en`）。
- 游戏内入口：主菜单 → 设置 → **语言**（`自动（跟随 Steam）` → `简体中文` → `English`）。
- **命令行覆盖**（不开 Steam 也能测英文）：`client.exe --lang en` / `--lang zh` / `--lang auto`；
  优先于 Steam 与本地设置（仅本次启动生效，不写回 `settings.txt`）。
  也接受 `chinese`/`english` 等码，大小写不敏感；缺参/非法值忽略。
- 也可直接手改 `%APPDATA%/warlock_brawl/settings.txt` 里的 `lang=auto|zh|en`。

## 三、怎么写文案

1. **静态文案**：直接在 UI 里写中文即可 —— `draw_text` / `ui::text_left|center|right`
   在**绘制时会统一过一层 `i18n::t`**。新增词条只需在 `i18n.rs` 的 `EN` 表补一行。
2. **含变量的文案**：`format!` 出来的完整串查不到词条，必须用命名占位：
   ```rust
   i18n::tf("剩余 {secs}s", &[("secs", format!("{:.0}", secs))])
   ```
   中文与英文词条都写 `{名字}`，由 `tf` 做字面替换。
3. **不要在 `t` 里传用户数据**（玩家名/房名/Steam 昵称）——中文用户输入可能与词条撞车。
   本项目的用户数据总是嵌在更大的模板里（如 `format!("{name} 的房间")`），因此不会被误翻。
4. **日志（`eprintln!`）不翻译**：保持中文便于我们排查。

## 四、测试与守卫

`client/src/i18n.rs` 单测（始终跑）：

- `en_table_has_no_duplicate_keys` / `en_table_values_are_nonempty`：词条表自身一致性。
- `every_explicit_t_key_in_source_is_translated`：扫源码里所有 `i18n::t("…")` / `i18n::tf("…")`
  的**字面量 key**，缺词条即红 —— 「全量覆盖」的守卫。
- `steam_code_mapping_*` / `lang_pref_*`：Steam 语言码映射与 `Auto/Fixed` 解析。
- `language_switch_drives_t_and_tf`：纯函数版 `t_for`/`tf_for`（不改全局状态，可与其它测试并行）。

> 注意：`t`/`tf` 用全局语言，测试**不要**改全局状态（会与并行用例串扰）——用 `t_for`/`tf_for`。

## 五、英文文案来源

- **优先取 098c 原始地图**（`098c/out/w3a_strings.txt`）里的英文原文（技能名/提示/播报），
  例如 `Releases a fireball`、`Shield is ON`、`Draw! One more round to decide the battle`。
- 技能描述（`game-core/src/skill.rs` 的 `DefTable::desc`）以中文为准直译；
  名册技能名与 098c 对齐，遗留（Unity 版旧技能）名称亦已收录。
- 键位提示（`keys::CONFIRM_HINT` / `SELL_HINT`）作为 key 收录，避免与主界面文案脱节。

## 六、加一门新语言（示例：繁中 / 日文）

1. `Lang` 加变体 + `code()`/`native_name()`/`from_steam_code()` 映射；
2. `EN` 表旁再加一张 `JA` 表（结构相同），`t_for` 里按语言选表；
3. `LangPref::all()` 自动带上新语言（设置行循环项）；
4. `from_steam_code` 已把未支持语言统一回退英文，按需改成映射到新语言。
