# 098c JASS 两字母字段词典（考古记录）

> 目的：把 `war3map_pretty.j` 里那些两字母短名（`Q/S`、`U/w`、`ev/gv`、`Av/Bv/Nv`…）的**含义与证据**固定下来，
> 供后续所有技能普查引用。**格式约定**：每条都给 `函数名(行号)`；没有把握的一律标 `❓待查`，不猜。
>
> 代码真值优先级：`war3map_pretty.j` ＞ `w3a_strings.txt`（tooltip，仅作交叉验证）＞ 本仓库旧文档（**可能出错**）。

## 0. 前置：JASS 标识符**大小写敏感**（这一点决定了很多推断）

`war3map_pretty.j` 的全局声明区（1–500 行）把大小写不同的名字**分别声明、且类型不同**：

| 行 | 声明 | 行 | 声明 |
|---|---|---|---|
| 29 | `real array z` | 30 | `boolean array Z` |
| 32 | `real array ev` | 40 | `integer array Ev` |
| 35 | `integer array rv` | 43 | `real array Rv` |
| 37 | `boolean array av` | 45 | `boolean array Av` |
| 53 | `boolean array fv` | 54 | `integer array Fv` |
| 61 | `integer kv=0` | 62 | `integer Kv=0` |

⇒ `z`/`Z`、`rv`/`Rv` 等**是不同变量**（否则 `set S[gX]=(S[gX]-z[gX])*.96` 与 `if Z[gX] then` 无法共存）。
**推论**：`kv` 与 `Kv` 也是两个不同的全局变量（见 §3.6）。

## 3. 关键机制（由上面的字段推出，逐条给证据）

### 3.1 伤害 / 击退三兄弟：`hI` / `mI` / `KI` / `MI` / `SI` / `tI`
- `hI(HI,JR,HX,dx,dy)`(6907)：**只结算伤害**（带来源与方向，用于表现）。
- `mI(HI,JR,HX,lI)`(7051)：`dx,dy = K[JR]-K[HI]`（**径向**，弹体→目标）；`LI=('d'+gn[JI])*HX*Gn[jI]*hn[JI]*.03*Hn[JI]*lI`；`Q[JR]+=LI*dir` + `call hI(...)`。
  ⇒ **`lI` 就是 tooltip 里的“xx% knockback”**（S015 簇射 `.65` ↔ tooltip “65% knockback”）。
- `KI(HI,JR,HX,lI)`(7001)：方向改取**攻击者速度方向**（`Q[HI],S[HI]`）；`LI` 公式同上。
- `MI`(7115)：只推不伤（无 `hI`）。
- `SI/tI`：AoE 变体（群体结算）。
- 特例：`fv[JR]`（**目标飞行中**）→ `LI='d'*HX*lI*.03`（不吃 `Gn/hn/Hn`）；`Dv[JR]`（**目标是可摧毁柱**）→ `LI=0`（只受伤不被推）。

### 3.2 碰撞判定（我方 `missile_collision` 的原型）
```
if Av[3*gX+nv[fA]] and Av[3*fA+nv[gX]] then            // 双向掩码
 if (Bv[gX] or Bv[fA])                                  // 撞一切
    or ((Vv[fA]!=Vv[gX]                                 // 不同主
         or (bv[gX] and nv[fA]==1) or (bv[fA] and nv[gX]==1))   // 或“允许撞自己人”
        and (cn[Vv[gX]]!=cn[Vv[fA]] or (Nv[gX] and Nv[fA])))    // 不同队，或双方都允许同队
```
（`8397`–`8420`）。命中后按 `cv` 优先级决定谁的 `hv` 先跑（`cv[x]>=cv[y]`），**两边都可能跑**。

### 3.3 柱子（class 3）与地形墙不是一回事
- **柱子**是 `rO(3)` 对象（`AN`(9440) 激活装饰层、`PillarShard_Respawn`(9063) 重建），`hv=IN`(8963)→`WA`(8980)：
  把撞上来的对象推到柱面外 + **沿接触法线的弹性反射** `v' = v − (1+xv)(v·n)·n`（`xv=1` → 法向取反、切向保留；`xv=-1` → 只消掉法向）。
  柱 HP = `gv`，初始 `nx`（`set gv[gX]=nx`，`YA`(9043)），**伤害由弹体自己的 `hv` 决定**（不是柱子自动挨打）。
- **地形墙**：`RA(px,py)==6`（65 宽的路径网格，`kw`/`kx` 数组）→ `Q[gX]=-Q[gX]*xv[gX]`（按轴取反，`8660/8676`）。
  另有地图硬边界 `Nr/Br/br/cr` → 速度**减半**反向（`8707/8718`）。

### 3.4 `ev`/`gv` 的复用陷阱
`gv` 在柱子上是 HP、在弹体上是伤害/治疗量、在回旋镖上是回程弧时长 —— **同名不同义**，查代码时必须看创建处。

### 3.5 我方与 098c 的换算
- 098c 的 `Q/S/U/w` 是**每 tick(0.03s)**；换到“每秒”要 `÷0.03`（速度）或 `÷0.0009`（加速度）。
  本仓库多次踩坑：`tb/100`（回旋镖弹开）、`y1` 拉拽 `1.4/tick`、`18/s` 之类。
- 098c 的 `ev`/时长是**秒**（`*.03` 出现在 `ev` 计算里，如 `ev=-wb/yb*.03`）。

### 3.6 `kv` vs `Kv`：`Kv` 只走**术士**（定论，2026-09-22）
由 4 处代码唯一确定（不需运行）：
1. `eO`(3443) `xO==2/3`（弹体/障碍）：`set rv[id]=kv; if kv!=0 then set iv[kv]=id endif; set kv=id`
   ⇒ `rv`=next、`iv`=prev、`kv`=**全表头**。
2. `eO` `xO==1`（**只有术士用**，全图仅 `4953: Xn[i]=OO(1,i,jo,...)` 12 处）：
   `set rv[id]=Kv; if iv[Kv]!=0 then iv[id]=iv[Kv]; rv[iv[Kv]]=id endif; set iv[Kv]=id; if Kv==kv then kv=id endif; set Kv=id`
   ⇒ 新术士插在“当前 `Kv` 之前”，`Kv` 恒指向**最新创建的术士**；因为每个新术士的 `rv` 指向上一个术士，从 `Kv` 沿 `rv` 走 = 遍历**全部术士**（到第一个术士 `rv=0` 结束）。
3. `oO`(3520) 脱链 + `if id==Kv then Kv=rv[id]` ⇒ 这一句只有在 `rv[Kv]` 指向“上一个术士”时才成立（若 `Kv` 是全表尾则 `rv[Kv]=0`，会毁链表）。
4. 碰撞循环(`8397`)用 `gX=kv; gX=rv[gX]` 且能碰到 `nv==1/2/3` ⇒ 从 `kv` 确实走全表。

**⇒ 从 `Kv` 走只访问 12 个术士**：`rc`(13173)、`oc` 友军分支(13073)、`Mb`(11161)、`eC`(14460) 等“找最近对象”**都只考虑术士**，永不选柱子/弹体；
其中 `rc` 需 `gX!=Er` 排除施法者本人。`eC` 里那句 `not Dv[gX]` 是**死代码**（不能当反证）。
反之**陨石 `oB`(11562) 用的是小写 `kv`** + `(nv[gX]==1 or Dv[gX] or fv[gX])` → 它**会**砸到柱子。

### 3.7 时间回调：`LO`
`wv[(LO(function YB, 时长, 单位, 参数…))]=<特效>` —— `LO` 注册一个“到期执行”的回调。
`YB`/`yB` 就是 S014 用来**到期归还**移速(`YB`)与输出倍率(`yB`)的回调（我们以 buff 到期自动恢复等价实现）。
