# 改键（Keybindings）整体规划

> 目标：把"改键"从"只有 8 个技能槽能改"升级为一套**覆盖全游戏、规则明确、可验证**的输入绑定系统。
> 本文先固定**现状事实**，再给**目标设计**与**分期计划**，最后列出需要拍板的开放问题。
> 相关：`UI_MASTER_PLAN.md`（界面清单）、`I18N.md`（文案）、`HANDOVER.md`（进度）。

---

## 0. 速答（本次两个问题的结论）

1. **"卖出"这个按键存在吗？**
   存在。`BindAction::Sell` 是第 10 个可绑动作，**默认未绑定**（`key_sell=` 空），
   但**固定别名**恒有效：商店页 `退格/Delete` = 卖出；详情里也有带快捷键的 `[卖出]` 按钮。
   之所以"像没有"，是因为默认值显示为「未绑」，且它只在**商店页**有实际作用。

2. **现在能把 J/K/L 改到技能键上吗？会不会和技能菜单冲突？**
   能。`valid_bind_char` 允许 `a-z/0-9` 与若干符号，`j/k/l` 是合法技能键。
   冲突规则是**固定键优先**：学习页的 `J/K/L` 是页签（技能/商店/成长）且优先级最高，
   所以把技能键改到 `j` 后——**对战中按 `J` 正常施法**；**学习页按 `J` 只会切页签**，
   该技能树无法用 `J` 选中（只能用数字键/鼠标）。
   代码上体现为 `LEARN_RESERVED`（学习页选树循环跳过这些字符）+ 绑定时对**非技能动作**直接拒绝。
   → 这不算"崩"，但是**沉默的陷阱**：见 §5，需要决定策略（允许并明示 / 直接禁止）。

### 1.3 能力边界（关键限制）

绑定值目前只能是**单个字符** `char`。因此
`Space` / `Enter` / `Delete` / `F10` / 方向键等**命名键**无法被"真正重映射"，
只能以**写死的固定别名**形式兜底（购买=回车、卖出=退格、静音=F10、镜头=Space/Home/1/End/2）。
→ 这是 T3 要解决的根问题（升级为 `BindKey = Char | Named`）。

## 2. 问题清单

- **P1** `S`（停止移动）不可改 —— 对战高频键，影响手感。
- **P2** 镜头 6 个键（回中心/跳自己/跟随/平移）不可改，且**入口都看不到**。
- **P3** 绑定值只有 char，命名键只能当别名（见 §1.3）。
- **P4** `J/K/L` 双重身份：学习页固定页签 vs 技能键选树。**固定键沉默胜出**，玩家无提示。
- **P5** 数字键双重身份：学习页选行 vs 对战 `1`/`2` 镜头。现靠 phase 区分；而 `LEARN_RESERVED` 把 `0-9` 全部列为保留，导致购买/卖出/静音**不能绑数字**（可考虑放宽）。
- **P6** `LEARN_RESERVED` 里的 `-` 在当前代码里**没有任何使用点**（陈旧项，应清理或补上用途）。
- **P7** 冲突提示只有一句文案，不告诉玩家"这个键在哪个界面已被谁占用"。
- **P8** 无本地导入/导出（云同步已有，但调参/分享不方便）。
- **P9** "未绑定"与"存在固定别名"并存，容易让玩家以为没生效（卖出就是典型）。

## 3. 设计原则

1. **分层**：**固定键**（导航/鼠标/修饰键）与**可改键**（玩法/镜头/动作）分离；
   固定键永远优先，但**任何遮蔽都要在 UI 里可见**（不能沉默）。
2. **作用域化冲突**：`Global` / `Battle` / `Learn`；**同域内唯一**，跨域允许重叠。
3. **默认值 = 现状**：升级后老玩家零迁移（按 `S` 仍停、`Space` 仍回中心）。
4. **绑定值升级**：`BindKey = Char(char) | Named(NamedKey)`，覆盖 `space/enter/delete/f10/home/end/up/down/left/right` 等。
5. **一次只改一个动作**；改键即时落盘 + 云同步；`R` 一键恢复默认。
6. **可验证**：所有按键判定必须走绑定表，用**源码扫描测试**防漏改。

## 4. 目标数据模型

```rust
enum BindScope { Global, Battle, Learn }

enum BindAction {
    Skill(u8),      // 8 个技能槽（Battle）
    Stop,           // 停止移动 + 清队列（Battle）
    CamCenter,      // 镜头回中心（Battle）
    CamSelf,        // 镜头跳到自己（Battle）
    CamFollow,      // 镜头跟随开关（Battle）
    Buy,            // 购买/升级（Learn）
    Sell,           // 卖出（Learn）
    Mute,           // 静音（Global）
}

enum BindKey { Char(char), Named(NamedKey) }  // Named 只允许白名单
```

默认表（**与现状完全一致**，均为可改）：

| 动作 | 默认 | 域 |
|------|------|---|
| `Skill(0..7)` | `c r e d y t f g` | Battle |
| `Stop` | `s`（**新增**，取代写死） | Battle |
| `CamCenter` | `space`（`home` 作为**附加**默认别名可保留） | Battle |
| `CamSelf` | `1` | Battle |
| `CamFollow` | `2` | Battle |
| `Buy` | `=`（`enter` 附加别名） | Learn |
| `Sell` | `delete`（`backspace` 附加别名） | Learn |
| `Mute` | `f10` | Global |

持久化（向后兼容：旧字段照读，新字段缺省取默认）：

```
skill_keys=c,r,e,d,y,t,f,g
key_stop=s
key_cam_center=space
key_cam_self=1
key_cam_follow=2
key_buy==
key_sell=delete
key_mute=f10
```

> 兼容性：`key_buy==` 这种"值本身是 `=`"的写法 `split_once('=')` 取第一段，没问题（现有解析已是如此）。
> 旧版本存档（`skill_keys=...` + 空 `key_buy`）读取后自动补默认。

## 5. 冲突与优先级规则

### 5.1 唯一性

- 同一作用域内**不允许重复**绑定（`bind_conflict` 扩展为按域比较）。
- **跨作用域允许重叠**（例：技能键 `c` 与大厅某键 `c` 互不影响）。
- **固定键清单**（§1.2 中除可改项外的全部）：绑定动作**不得**占用 `Esc/Q/Tab/Enter/Shift/鼠标/滚轮`。

### 5.2 学习页优先级（自上而下，高者胜）

| 优先级 | 键 | 归属 |
|--------|----|------|
| 1 | `J/K/L`（`F1-F3`） | 页签（固定） |
| 2 | `1`–`9`,`0` | 选行/选技能/选成长（固定） |
| 3 | `N`/`M` | 商店分类（固定） |
| 4 | 技能键 | 选技能树（**可改**） |
| 5 | `Buy`/`Sell`/`Mute`/其余动作 | 购买 / 卖出 / 静音 |

### 5.3 当可改键落在 1–3 上（**需决策**）

- **策略 a（现状）**：允许绑定，学习页固定键胜出，选树静默跳过。
  - 优点：最自由；缺点：**沉默陷阱**（技能键在学习页"失灵"）。
- **策略 b（推荐）**：允许绑定，但**必须在两处明示**：
  1. 绑定成功时提示"注意：学习页此键用于 `<页签/选行>`"；
  2. 学习页里该技能树上显示灰字 `[J] 已用于页签`。
- **策略 c**：直接**禁止**技能键占用 `J/K/L`（提示"该键被学习页固定占用"）。
  - 优点：零困惑；缺点：少数玩家想用 `JKL` 顺手施法时被挡。

> 我的建议：**b**（保留自由 + 消灭沉默）。

## 7. UI 设计（「设置 → 按键设置」）

```
┌ 按键设置 ──────────────────────────────┐
│ 战斗                                    │
│   C 槽技能            C      ← 可改     │
│   R 槽技能            R                 │
│   …                                     │
│   停止移动/清队列      S                │
│ 镜头                                    │
│   回场地中心          SPACE             │
│   跳到自己            1                 │
│   跟随自身            2                 │
│ 商店                                    │
│   购买 / 升级         =                 │
│   卖出 / 取消         未绑               │
│ 系统                                    │
│   静音                F10               │
│ ─────────────────────────────────────── │
│ 固定键（不可改）：Esc/Q 返回 · ↑↓←→ …   │
│ ↑/↓ 选择 · 回车 改键 · R 恢复默认 · Esc 返回 │
└─────────────────────────────────────────┘
```

- 分组标题 + 可改行高亮；**未绑定**行用暗色。
- 固定键区**只读灰显**（让玩家知道"这些键改不了，也不该改"）。
- 捕获中显示「请按键…」；成功/冲突/无效三类提示。
