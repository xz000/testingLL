# 主动离开 + 三因归队 设计规划（LEAVE_REJOIN_PLAN.md）

> **目标**：对局中「主动离开」（房主/玩家）立即生效、不按掉线等待；且**主动离开 / 掉线 / 崩溃**三因都能**手动重新加入上一局**。世界玩家**数量/索引不变**（帧同步红线）。
>
> **状态（2026-10-11 定稿）**：基于**真实代码现状**（R5c/R6b 已完成）。全部决策已拍板：
> - **Q1 = B**：主动离开**退出大厅**，但**保留归队会话**，归队走"按 id 重进大厅"（复用崩溃归队路径）。
> - **Q2 = 做**：新增 `Packet::Leave`，主动离开**立即生效**（房主立即触发迁移；非房主被 host 立即标记）。
> - **Q3**：归队会话上限 **12h 固定**（**不做周期刷新**），但**预留"时长可配置"的接缝**；真正判定 = 归队时 join 是否成功。
> - **Q4**：回主菜单**只提示、手动归队**。
> - **后续确认**：① 退出确认文案**区分房主/玩家 + 补归队提示**；② 全端统一标 **"已离开"**（合并 `Leave` 与 3s 掉线，不做区分）；③ 房主广播**统一"在线集"**（既用于标记，也用于迁移选举）。
>
> 关联：`EXIT_MENU_RECONNECT_PLAN.md`（E1 已落）· `archive/STEAM_MULTIPLAYER_PLAN.md` · `client/src/rejoin.rs`。

### 0.2 真正的缺口（本规划要做的）
1. **主动离开 = 全量拆除**：`Escape→返回主菜单` → `leave_match()` → `reset_to_main_menu()`，它**退出大厅** + **`rejoin::clear()`（删会话）** + 清空全部状态 ⇒ **主动离开者无法归队**、主菜单不提示。
2. **无 `Packet::Leave`**：房主要等 3s(stale)+1.5s(probe) 才被判定离开；非房主离开、host 要等 180 tick(3s) 才 `mark_dropped`。
3. **归队会话 30 分钟硬过期**（`rejoin::MAX_AGE_SECS`）。
4. **"谁掉线/离开"不广播**：`dropped` 仅房主可见 ⇒ 普通 client 无法标"已离开"。
5. 退出确认文案**未提"可归队"**（且非房主无任何提示）。

## 1. 不变式
1. 世界 `players` 数量/顺序固定 —— 离场/掉线/归队都用 `mark_dropped` 站桩占位。
2. 所有"回主菜单"路径须**区分**"我离开本局（保留会话，可归队）"vs"干净退出/失败回退（清会话）"。
3. 主动离开的广播是 **best-effort** —— 丢包由现有 3s 兜底。
4. `Packet::Leave` 与"在线集"广播都**不进 World** ⇒ **不升 `PROTOCOL_VERSION`**（改 `proto.rs` 补 roundtrip）。

## 2. 设计

### 2.1 归队会话生命周期（Q3）
**以"能否真的加入"为准，而非固定时长。**
- **写**：进房成功时（已有）。**不做周期刷新**（12h 上限足以覆盖任何现实对局；`saved_at` 仅作显示用）。
- **保留（不 clear）**：对局中主动离开、迁移失败、归队握手超时 → 回菜单仍可再试。
- **清除**：① 用户显式忽略提示（Esc）；② "干净退出房间"（房间阶段 `Q` = `steam_leave_room`）；③ **对局确实结束**——由"重进大厅失败（join 报错）"判定；④ 格式/协议不符（本就会忽略）。
- **上限**：**12 小时固定**（替换原 30 分钟）。语义 = "距你最后一次在局里 12h"。
  - **可配置接缝（预留）**：上限**只在一处取值**（`rejoin` 暴露单一入口，如 `pub fn max_age_secs() -> u64`，或将来改由 `LocalSettings` 字段提供）。调用方只读这一处 ⇒ 将来加"设置行 + 持久化 + 云同步"是**换来源**，不动逻辑。
- **判定**：真正"这场局还在不在" = **归队时 `join_lobby` 是否成功 + 是否收到 `Snapshot`**（无便宜的旁路探测；不做额外探测器）。
- **主菜单提示刷新**：现在只在**启动**读盘 ⇒ 增加"每次回到主菜单时"重新装载（同进程主动离开后立刻可提示）。

### 2.2 `Packet::Leave { identity }`（Q2）
- `net/src/proto.rs`：新增变体 + 编解码 + `roundtrip_all_packets`。**不升协议**。
- **client→host**（非房主主动离开）：host 收到 → **立即** `mark_dropped(identity)`（不等 180 tick），并把该身份**移出"在线集"**（见 2.3）。
- **host→all**（房主主动离开）：各 client 收到 → **跳过 3s stale + 跳过 probe**，直接进入选举迁移；收不到 → 现有 3s 兜底。
- 增强（可选）：房主离开前**再广播一次最终 `Snapshot`**，让新 host 的缓存快照更准。

### 2.3 统一"在线集"广播（标记 Q3-③ + 选举）
- 房主维护一份**在线集** = 参与集 − 当前"已离开/掉线"者。
- **更新时机**：收到 `Leave`（立即移除）· `auto_drop_idle` 自动掉线（移除）· `ReconnectReq`/`unmark_dropped` 重连（加回）。
- **广播**：复用现有 `Packet::Participants { ids }`（形状不变 ⇒ **不升协议**）；client 已在 `recv_participants`（`main.rs:7191`）接收。
- **一集两用**：既供 client 渲染"已离开"标记，**也供迁移选举**（当前 `steam_online` 只排除旧 host；改为同样反映掉线 ⇒ **选举不会选到已不在线者**，更稳）。⇒ 把"标记用在线集"与"选举用在线集"**统一为同一份**。

### 2.4 主动离开流程（Q1=B, Q4）
```
对局中 Esc →「返回主菜单」二次确认
  ├─（房主）广播 Packet::Leave{me}（best-effort）  /（玩家）向 host 发 Packet::Leave{me}
  ├─ persist_rejoin_session()（**保留**，不 clear）
  ├─ leave_lobby（退出大厅）
  ├─ 回主菜单：重置对局状态，但 **回填 steam_rejoin_prompt = Some(session)**
  └─ 主菜单立即显示「重新加入上一局」（手动回车/Y 归队）
归队 = 复用现有 R5c：join_lobby(id) → rejoin 握手 → Snapshot → 续打
```
- 归队失败：**join 报错（大厅已关）** → 清会话 + 提示"上一局已结束"；**仅握手超时** → **保留**会话（可重试）。

### 2.5 归队（三因统一）
- **掉线（进程在）**：现有 `ReconnectReq` 重连/迁移。
- **崩溃（进程没了）**：现有 R5c（读 `rejoin.txt` → 重进大厅 → 握手）。
- **主动离开（新）**：同崩溃路径（会话保留 ⇒ 主菜单提示）。
- 归队后：host 按稳定身份（SteamID）找回槽位 + `unmark_dropped`（整局保槽）。

### 2.6 "已离开"标记（全端一致，合并掉线/离开）
- 依据 = 2.3 的**在线集**：不在其中的槽位 → 标 **"已离开"**（**不再区分**主动/掉线）。
- 渲染位置：玩家名牌 / HUD 槽位处（具体实现时定）。
- 效果：房主与所有 client 看到**同一份**状态；重连回来后标记消失。

### 2.7 退出确认文案（区分 + 补归队）
- Steam 房主：`你是房主：离开后其他人会接管本局；你可在主菜单重新加入`
- Steam 玩家：`离开后你可在主菜单重新加入本局`
- LAN 房主：保持"会中断对局"（局域网无归队）。
- 位置：`main.rs:4905` 附近的 `warn` 提示行。

### 2.8 槽位/窗口
- **整局保槽**（现状）。主动离开者站桩占位、可被击杀（已同意）。

## 5. 测试策略
- **纯函数/单测**：`rejoin` 12h 边界；上限单一取值；`reset` 清/留两径；host `Leave` → `mark_dropped` 且在线集移除；client 收房主 `Leave` → 进入迁移（跳过 probe）；在线集变化 → 标记集合正确。
- **`net` 单测**：`proto` roundtrip（新 `Leave`）；复用 `host_auto_drops_idle_client` / `host_all_cfgs_ignores_dropped_client` 思路。
- **真机双账号**（每步）：
  - L2：非房主返回主菜单 → 房主**立即**显示其"已离开"（不再等 3s）；房主离开 → 其余**立即**开始迁移。
  - L3：房主与另一 client 看到**相同**的"已离开"；重连回来后消失。
  - L1/L4：主动离开者回菜单**立即**看到"重新加入上一局" → 回车回到原局（同一槽位）；join 失败 → "上一局已结束"并清会话。

## 6. 风险与边界
1. **帧同步红线**：一切离场/归队不得改世界玩家数/索引。
2. **Leave 丢包**：best-effort；**必须保留 3s 兜底**（L2 不删旧机制）。
3. **统一在线集的双刃**：把它用于"选举"后，被移除者**当次迁移不会被选为新 host**（其不在线，本就不该选）；重连回来后加回。需验证不影响正常迁移。
4. **归队失败区分**：join 报错（大厅已关）= 对局结束 → 清；握手超时 = 网络问题 → 留（可重试）。
5. **房主退房时序**：需确保可靠通道把 `Leave` 送出去（Steam 可靠包会排队；若有疑虑，加"退房后仍泵一帧回调"）。
6. **可配置接缝**：12h 隐藏在单一取值点；将来加设置行时**不引入散落的魔法数**。
