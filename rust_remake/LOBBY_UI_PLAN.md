# 大厅 / 建房 / 房间 UI 重构计划

> 起因：房间设置编辑器做好了却"按 `O` 没反应"。确诊后发现**不是逻辑错，而是架构问题** ——
> 详见下面「问题清单 1」。这与之前重构商店时遇到的坑是同一类，所以按同样的思路重构。

## 一、问题清单（都带证据）

### 1. 覆盖层绘制散落在各状态的"早期返回"里 → 漏画
大厅有 5 个子界面，各自**独立绘制且提前 `return`**：

| 行号 | 绘制调用 | 状态 |
|---|---|---|
| 2680 | `draw_steam_room_edit` | 房间信息编辑 |
| 2682 | `draw_steam_ready_overlay` | 房间（就绪/等待） |
| 3271 | `draw_steam_friend_panel` | 好友面板（叠在房间上） |
| 6570 | `draw_steam_create_lobby` | 建房设置 |
| 6577 | `draw_steam_lobby_list` | 房间列表 |

编辑器原先只在**房间**状态那次调用之后画 → **建房/列表界面按 `O` 毫无反应**。
（修复：在 6570/6577 的返回路径里各补一次调用 —— 但这是**打补丁**，不是解决结构问题。）

### 2. 键位分散、易冲突
目前大厅各界面各自处理按键，已用到的字母：`I`（好友面板）、`U`（就绪）、`Q`（退出）、
`E`（改房间信息）、`O`（设置编辑器）、`R`（刷新/回血）、`M`（模式）、`F`（筛选）、
`J/K/L`（配置页签，对局中）、`Tab`/箭头（导航）、以及各文本字段的直接输入。

问题：**同一字母在不同子界面含义不同**，且没有一处能一眼看全（对照：商店重构后，
`LearnAction` + `shop_rows` 把"标签/键位/动作"三者的来源收敛到了一处）。

### 3. 设置编辑入口不完整
- 非 Steam（单机/局域网）路径**没有**编辑器（字段是 `#[cfg(feature = "steam")]`）——
  而 `match_cfg` 本身是非 Steam 路径也在用的。
- 建房界面仍是"8 个字段 + 方向键导航"，与新的四组设置编辑器**并存但风格不一**。

## 二、重构方向（照搬商店那套成功经验）

商店重构做对的三件事，这里逐一对齐：

| 商店做法 | 大厅对应做法 |
|---|---|
| `LearnAction` 枚举统一"动作" | 新增 `LobbyAction` 枚举（进入/返回/就绪/编辑设置/调值/建厅/加入/刷新…） |
| `shop_rows()` 统一构造"行（标签+动作+说明）" | `lobby_rows(screen, &state) -> Vec<(String, Option<LobbyAction>, &'static str)>`，**绘制与键盘共用** |
| 页签 + 统一确认键（`keys::confirm_just`） | 扩展 `keys.rs`：`keys::lobby_confirm`、`keys::lobby_cancel`、`keys::nudge(dir)` 等 |

另外补上商店当时没解决的一点：

4. **单一绘制管线**：`LobbyScreen` 状态机（`Menu / List / Create / Room / Editor`）+
   一个 `draw_lobby()` 统一入口，**覆盖层（设置编辑器、好友面板、提示条）统一在最后绘制**，
   各子界面**不再提前 return**。→ 本次这类"漏画"从结构上不可能再发生。

5. **设置编辑器升级为独立 screen**：可从任何大厅状态进入（`O`），`Esc/回车` 返回**来源状态**
   （而不是回到某个固定界面）。

## 三、迁移步骤（每步独立可提交、随时可停）

1. **引入 `LobbyAction` + `lobby_rows()`（纯逻辑 + 单测）**
   先把现有 5 个界面的行构造抽出来，**不改 UI 行为**；用单测钉住"每行标签 ↔ 动作 ↔ 键位"。
2. **引入 `LobbyScreen` 状态机 + 单一绘制/输入入口**
   把早退改成状态分派；覆盖层统一后画。此时 1 中的 `lobby_rows` 接管键盘。
3. **把设置编辑器接入新管线**，并去掉 `#[cfg(feature = "steam")]`（编辑器本身与 Steam 无关，
   只有"发布到大厅"那一步是 Steam 专属）。
4. **键位总表落进 `keys.rs`**，加"同一键在多个 screen 冲突"的检测测试
   （类似 `main_wires_shared_confirm_contract` 那样直接扫源码）。
5. **局域网/单机路径接入**（`net_host_ls` 侧的等价元数据与就绪语义）。

## 四、收益

- 这类"界面加了但按不出来/画不出来"的 bug 从结构上消失；
- 新增设置项或界面时，只需在 `lobby_rows` + `LobbyAction` 各加一处；
- 键位冲突可以在 CI 里查（现在只能靠人肉记）。
