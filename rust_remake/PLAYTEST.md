# Circle Brawl — 098c 试玩版（内部）

098c 全机制 2D 复刻的试玩版。纯文字+几何图形（无美术素材阶段），确定性帧同步联机。

## 构建

```bash
# 单机/LAN 版
cargo build --release -p client

# Steam 版（大厅/邀请/头像/排行榜）
cargo build --release -p client --features client/steam
```

产物：`target/release/client.exe`

## 运行

| 入口 | 命令 |
|---|---|
| 单机试验场（教学/试技能） | `client.exe` → 主菜单选 Solo，或 `client.exe --solo` |
| 局域网建主 | `client.exe --lan-host 7777 4`（端口 人数） |
| 局域网加入 | `client.exe --lan 127.0.0.1:7777` |
| Steam 建房 | `client.exe --steam-host` |
| Steam 直连某厅 | `client.exe --steam-join <lobby_id>` |
| 指定模式 | `--mode 1`（轮次）/`2` 死亡竞赛/`3` 化身/`4` 国王/`5` 最后生还 |

## 操作

- 右键移动；S 停手/清队列；Shift+指令入队
- 左键 = 火球（G 槽）；字母键 C/R/E/D/Y/T/F 选技能树内绑定的技能
- 学习期（局间）：字母选中树 → 数字绑定 → `=` 升级 → `B` 切换该技能 A/B 形态（免费）
- 精通：`U` 生命 / `I` 远程 / `O` 时间 / `P` 背包（不涨价，跨回合保留）
- 商店：数字键购买物品（升级链同键再购）；`-sell N` 语义见内建提示

## 模式（房间属性/命令行）

1. **轮次**（默认）：N 小局，活人全同队判胜，按总分排名
2. **死亡竞赛**：无回合，死 4 秒复活，死者 -1 分，先到胜利分获胜
3. **化身**：每轮伤害最高者当化身（半径 50、伤害 ×1.5、F=灾变），按伤害/20 计分
4. **国王**：两队各随机一王（F=虔诚奶友+加冕减免），弑王 → 凶手全队永久 -1hp/s
5. **最后生还**：死后观战，凶手死亡救活其受害者；存活者同凶即结算
