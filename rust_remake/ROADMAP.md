# 产品总规划（三大功能）ROADMAP

> 创建 2026-08-15。当前 Rust 重制已打通的核心基座：
> 确定性核心(game-core) + 完整 lockstep 网络层(proto/handshake/lockstep，含多局配置同步 4.6、
> 乐观预测 4.7 阶段一) + 本地多开验证。本文把之后的工作按【三大功能】重新组织。

## 三大功能（用户确认的目标）
1. **单机技能试验场** —— 无需 AI 的单机测试
2. **局域网对战** —— 本地/内网多端对战
3. **Steamworks 对战** —— 走 Steam 网络的回合对战

## 它们与现有代码的对应
| 功能 | 需要的模式 | 现状 |
|------|-----------|------|
| 单机技能试验场 | 单 `NetMode::Local`，**去掉 AI 机器人**，只控制自己 | 单机模式存在但**带 BOTS（7 个 AI）**，需加"无 AI"选项 |
| 局域网对战 | `--host` / `--join`（本地 UDP，host-authoritative lockstep） | ✅ 已基本打通（多开验证过：4 窗口正常、多局配置同步正常、乐观预测阶段一） |
| Steamworks 对战 | 用 Steam Networking 替换 `Transport` 底层，逻辑不变 | ⏳ 未做，但 `trait Transport` 抽象已为它铺好路 |

## 规划优先级与依赖
```
(最底层，已有)  确定性核心 + lockstep 网络层(可换底层 Transport)
        │
        ├─────────────► 单机技能试验场（最快，几小时）
        │                   · 无 AI 单机：本地控制自己，验证技能/伤害/手感
        │                   · 可复用同一 World/lockstep 状态机（只是无网络收发）
        │
        ├─────────────► 局域网对战（当前能力之上一小步：完善体验 + 房间/开局界面）
        │                   · 已是 host+join 多开可玩
        │                   · 补：开局界面、玩家名、对局结束/重开、局域网发现（可选）
        │
        └─────────────► Steamworks 对战（依赖 Transport 换代，工程量最大）
                            · 实现 `SteamTransport`（trait Transport）
                            · 接 Steam 大厅/房间 + Steam Networking 收发
                            · 需 Steam SDK（windows crate），非本地可测，需真机+账号
```

## 建议的落地顺序
1. **单机技能试验场**（最短、提供快速迭代手感的安全网）：
   - `--solo`（或 `NetMode::Solo`）单机模式，无 AI、只一个玩家，用来测技能/连招/伤害/数值。
   - 好处：以后调手感、写玩法、做 4.6b 属性系统都在这个安全试验场里快速验证，不依赖联网。
   - 实现：client 加 Solo 模式（复用 Local，但 BOTS=0），可能加"自由施法/无敌"之类调试开关（可选）。
2. **局域网对战体验补完**（在已打通的 base 上加 UI/流程）：
   - 开局房间界面（设置人数/开始）、客户端加入界面、对局结束/下一局、显示名次/金币。
   - 这是"可对外给人玩"的门面。4.6 多局已在局域网跑通。
3. **Steamworks 对战**（最大，独立阶段）：
   - 第一步：抽象确认 `Transport` 已足够（是）。
   - 第二步：接 Steam（大厅会话 + `SteamNetworkingSockets`/中继）实现 `SteamTransport`。
   - 第三步：把"开房间/加入"映射到 Steam 大厅，帧同步逻辑零改动。
   - 需 Steam SDK + 应用 AppID + 真机多账号，属发布级工程。

## 与既有计划的关系
- 本文是**产品层**的三线规划；`LOCKSTEP_FOUNDATION` / `NET_REWRITE` / `LATENCY_MASKING` / `ATTRIBUTE_SYSTEM` 是**技术基座**的专项。
- 属性系统(4.6b)、延迟掩盖完整回滚(4.7阶段二)、手感数值调优，都应在【单机试验场】里先做原型/验证，再进局域网，最后上 Steam。

## 里程碑（可验收）
- M1 单机试验场可玩（无 AI、自由测技能）—— 无网络依赖，最快。
- M2 局域网对战体验补完（开局/加入/名次/重开）可对外演示 —— 基于已打通的 lockstep。
- M3 Steamworks 对战 MVP（Steam 大厅 + SteamTransport 跑通多端）—— 交付级。

## 待定 / 需用户拍板
- 局域网是否要做"房间列表/自动发现"（内网广播），还是手动输 host:port 即可？默认先做手动。
- Steamworks 是否现在就需要预留 AppID / 账号测试环境？默认先做局域网 + 单机，Steam 立项后接。
- 「单机技能试验场」要不要顺带加演示级调试工具（无敌/重置技能 CD/看伤害数字）？默认含简单的一二个。
