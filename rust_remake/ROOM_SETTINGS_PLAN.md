## 二、我方设计（已定方向）

### 1. 经济组（8 项数值 + 初始金）
**全部开放为自由数值**（房主想怎么设就怎么设）：
`击杀金 / 助攻金 / 胜利金 / 伤害金 / 每轮金` + `击杀/助攻/胜利 点数` + `初始金币`。

> 已实装：默认值对齐 098c（`Qo=20`、`qo=10`、`lo=1`、`Lo=1`、`Mo=2`、`po=1`、`ko/Ko/mo=1/1/2`）；
> 伤害金算法已实现（回合最高伤害者得，含并列）。
> **待做**：把这些从常量变成房间可配项。

### 2. 玩法组

| 项 | 我方设计 | 理由 |
|---|---|---|
| **伤害倍率** | **档位**：75% / 100% / 125% / 150% | 整体改手感，自由数值易调出退化局面；与"回血档位"同构，UI/实现可复用 |
| **击退倍率** | **档位**：75% / 100% / 125% / 150% | 同上 |
| **岩浆伤害** | **档位**：关 / 低 / 标准 / 高 | 同上；"关"= 岩浆不掉血（练习用） |
| **第一轮配置期** | 自由秒数（默认 **40**） | 098c `Uo=40` |
| **局间配置期** | 自由秒数（默认 **30**） | 098c `uo=30` |
| **基础回血** | **档位**（已有）：`0.5/0/0.25/0.75/1.0/2.0` | 已完成 ✅ |
| **场地收缩** | **自由秒数 + 我方模型**（见下） | 098c 是阶跃，我方是连续 —— 参数语义必须按我方重定义 |
| **柱子** | **三态**：关闭 / 随机 / 每局必有 | 原版只能填索引或 0 |
| **冰面** | **三态**：关闭 / 随机 / 每局必有 | 原版绑在 `-league` 里，独立出来 |
| **地图形状** | 暂定**仅圆形**；后续可扩正方形/六边形 | 用户决定 |

#### 场地收缩（我方模型，必须与 098c 区分）

- 098c：**阶跃式**（`wo` = 每多长时间缩一档，离散台阶）。
- 我方：**连续缩小**（`shrink_timer` 到点后按固定速率连续收；测试
  `arena_shrinks_to_zero` / `shrink_is_continuous_after_delay`）。
- **因此参数语义改为**：`收缩延迟秒数`（开局静止期，之后开始缩）+ `收缩总时长秒数`（从开始缩到缩到 0 的时间）。
  比"每玩家多少秒一档"更贴合连续模型，也更好理解。
- 可选：`按玩家数缩放`（人越多缩得越慢/越快）作为**开关**，而不是把系数编进公式。

### 3. 模式开关
- **`-no reward` 等价项**：一个"关闭金币奖励"开关（一键把 5 项金币归零，保留点数）。
- **冰面**：独立三态（不再与联赛模式捆绑）。

## 三、房间 UI 重做

设置项已达 **20+**，必须分组。建议：

```
[经济]  [玩法]  [地图]  [模式]
```

- **经济**：8 个数值项（数字键选中 + `-/+` 或输入框调整）+ 初始金币
- **玩法**：伤害/击退/岩浆档位、两个配置期秒数、回血档位、收缩参数、冰面三态、柱子三态
- **地图**：形状（圆形，暂锁定）、场地随机/指定、"重掷"按钮
- **模式**：5 种玩法模式（已有）+ 关闭金币奖励开关

统一交互：`↑↓`/数字选中 · `←→` 调值 · 回车确认；沿用现有 `keys::confirm_just` 契约
（文案与键位同源，见 `client/src/keys.rs`）。
