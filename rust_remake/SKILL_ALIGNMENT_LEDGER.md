### 结论（已定论）：`kv` vs `Kv`——“近日老”两套入口，`Kv` 只走**术士**（2026-09-22）

由此4处代码可**唯一确定**链表语义（不需运行 JASS）：

1. `eO`(3443) 插入：`xO==2/3`（弹体/障碍）→ `set rv[id]=kv; if kv!=0 then set iv[kv]=id endif; set kv=id`
   ⇒ `rv`=next、`iv`=prev，且 `kv`=**全表头**（新对象插在最前）。
2. `eO` 的 `xO==1`（**只用于创建术士**，全图只有 `4953: Xn[i]=OO(1,i,jo,...)` 12 个）→ `set rv[id]=Kv`；
   `if iv[Kv]!=0 then set iv[id]=iv[Kv]; set rv[iv[Kv]]=id endif`；`set iv[Kv]=id`；`if Kv==kv then set kv=id endif`；`set Kv=id`。
   ⇒ 新术士总是插在**当前 `Kv` 之前**，且 `Kv` 指向**最新创建的那个术士**。
   （若在此之前插过弹体，`iv[Kv]!=0` 分支会把新术士插到“弹体 与 旧 Kv”之间，保持链不断。）
3. `oO`(3520) 移除：`if rv[id]!=0 then iv[rv[id]]=iv[id] endif`、`if iv[id]!=0 then rv[iv[id]]=rv[id] endif`
   （标准双向链表脱链）；`if id==kv then kv=rv[id]`（头尾移动）、`if id==Kv then Kv=rv[id]`
   —— **后者只有在 `Kv` 是“术士子链的头”时才成立**（术士子链的 `rv` 逐个指向上一个更早的术士，第一个术士 `rv=0` 收尾）。
4. 碰撞循环（8397）用 `gX=kv; gX=rv[gX]` 且能碰到 `nv==1/2/3` 与 `Av[3*x+1..3]` ⇒ 从 `kv` 确实走**全表**。

**⇒ `gX=Kv; gX=rv[gX]` 只会遍历 12 个术士单位**（新的→旧的，到第一个术士就 `rv=0` 结束）；
**弹体/障碍永远不在这个子链上**（它们挂在 `kv` 那一侧）。

推论与影响：
- `rc`(13173)、`oc` 友军分支(13073)、`Mb`(11161)、`eC`(14460)、以及其它“找最近对象”的函数（11164/11287/12178/13766/14796…）
  **都只考虑术士**，不会选到柱子/弹体；`rc` 需要 `gX!=Er` 排除施法者本人（本人在子链上）。
  ⇒ 我们“只搜玩家”的实现是对的；之前台账里写的“`rc` 候选含柱子/弹体”**是错的**（已改正）。
- `oc` 友军分支的 `gX!=Vr`（排除刚命中的那个）同理只看术士 ✓。

  —— 不能当作“`Kv` 含障碍”的证据。
