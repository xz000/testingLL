> 背景：仓库早期以 **098b** 为知识库（`port_098b/`）移植，后迁移到 098c（见 `098C_DIFF.md` 系统级差异）。

>

> 本审计一律以**代码**为准。

## 方法

1. 从 098c JASS 函数抽取公式：伤害 `call mI/SI/KI/tI/hI(...)`、时长 `set ev[...]=` 与
   `LO(function f, TIME, ...)`、射程/速度 `bO(...)`/`Q[]`、治疗 `PX/BX`。
2. 与 `SkillDef`（`damage_base/delta`、`duration_*`、`speed_base`、`max_distance_*`…）逐档对照。
3. 抽出代码里的**等级计数**（`Xv`/`zr`/`wr`/`Yr`/`yr`/`Ur`/`Wr`）——经学习代码确认：三选一的树
   （如 S014/15/16 的 `yr`）**≡ 技能等级**，故公式里的计数即等级。
