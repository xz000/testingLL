# 技能/单位状态对齐审计（098c ↔ 我们）

> 起因：`Burnout`（需要 `Hr` 燃烧冲刺）与 `Denied`（需要 `Fv` 链索绑定）两个播报**无法接入**，
> 说明我们的技能建模**只做了主效果**，098c 还给单位挂了**副状态机**。本文是系统性审计的第一版。
>

> 对给定数组输出引用数与 `set X[...]=` / 读取样例）。真值文件：`../098c/out/war3map_pretty.j`。

## 0. 结论（TL;DR）

- **技能主效果**：我们基本齐（每个技能有 `s0xx_*` 单测）；数值来自 `JASS_AUDIT_098c.md`。
- **副状态机**：098c 用**一批按单位/玩家索引的全局标志**驱动「附加交互」。我们**多数未建**：
  - 已知受影响：`S012`（燃烧冲刺的 Burnout）、`S019` 系链索（Denied 断链）。
  - 这些标志还可能门控别的行为 → 部分技能行为与 098c 有偏差（不是数值，而是**交互/状态**）。
- 这属于**玩法对齐**工作面，不是表现层；需要单独排期。

## 3. 已确认的技能副状态明细（定点深挖）

### 3.1 S012 燃烧冲刺（`Hr`）— 未建模
- 触发点：`SC=='S012' && !Fa[ri]` → `AB()`（war3map_pretty.j:16450-16458）。
- `AB()`(11916)：设 `Hr[ii]=true`、速度分量 `Q/S/U/w`、引信 `ev`、`Fr/gr`。
- 交互 `lb`(10961)：`Hr` 单位与**同队**单位距离 ≤ 45 → 对队友造成 `Xr=.45√(7+xi[team])` 伤害、
  写「Burn out」、清 `Hr`、速度 ×0.2（熄火）。
- 影响：**音效 Burnout 缺失**，且 S012 的「撞队友熄火」玩法我们也没有。

### 3.2 链索/束缚（`Fv`/`nv`）— 结构不同
- 绑定：`Mb`(11162) 取最近敌人 → `Fv[nr]=zO`；`nv[nr]=fi`（链类型）。
- 解绑：`aR`(4711)：`nR=Fv[gX]`，若 `nv==2`（束缚）则 `iO(nR,true)`；`Fv[gX]=0`。
- 「Denied」：`mC/qC/QC`（AOE 结算）中，若 `Fv[gX]==ii` 且（岩浆/`kr`/`Fr`）→ `aR(gX)` + 「Denied」。
- 影响：**音效 Denied 缺失**；链索的「可被天罚打断」交互也未建模。
