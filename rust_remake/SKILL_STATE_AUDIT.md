## 0. 结论（TL;DR）

098c 的按单位/玩家数组可分三类：

1. **War3 傀儡单位管线（实现细节，我们已用原生 `Projectile` 替代，不欠）**：
   `Av`（技能可用性 `id*3+n`）、`hv/jv/Gv`（boolexpr 条件/动作）、`Rv`（傀儡状态 id）、`ev`（傀儡寿命）、
   `Xv/Ev/cv`、`Q/S/U/w/Y/z`（傀儡速度/坐标增量）、`F`（傀儡单位）、`H`（闪电线）。
   → 098c 每次施法都 `CreateUnit` 一个傀儡承载法术；我们用 `Projectile`/区域/即时效果直接表达。**这不是缺口**。
2. **按玩家记账（基本已对齐）**：`Nn/bn`（在场/存活）、`cn/Vv`（队伍/归属）、`Rn`（本轮伤害）、
   `dn/Cn`（连杀计数/时刻）、`Fn`（当前 HP）、`Gn/Hn`（伤害/击退倍率）、`vi/ei/xi/oi/Zr`（等级/成长）。
3. **真·玩法副状态（少量，才是缺口）**：
   - `Hr`（**S012 A 燃烧冲刺**）→ Burnout；**✅ 已建（2026-09-13）**。
   - `Fr/gr`（**S010 A**）/ `fr`（**S010 B**）：带 debuff `gR` 的标记状态；
     **✅ 已核**：`Fr`/`fr`=风步/冲锋隐身（已对齐）；`gr`「招架刷新」与 `CA` 接触伤害分支未对齐（不影响播报）。
   - `kr`（**S012 B 凤凰**瞬时状态）：我们有凤凰实现，**大概率等价**。
   - `Fv` + `Dv/fv/Nv/bv/Bv` + `Mb`：**通用「链接/绑定」系统**（S003/S005/S013/S017B/S019 等都用），
     我们按弹体实现，缺少「单位级绑定」及其交互（Denied）。**结构不同**。

→ **不是「很多技能没对齐」，而是 3 处技能的副状态**：S012 燃烧、S010 标记、通用链索绑定。

#### 0.5 基础模型：**098c 无普通攻击**；`hv[unit]` = 碰撞（接触）条件

**重要结论**（2026-09-13 实证）：098c **没有自动/普通攻击**设定。技能状态之间的交互靠**单位碰撞**驱动：
- 物理积分函数 `DA`（~8000+）在**两单位相碰**时，以 `nr`/`Vr` 为配对去
  `TriggerClearConditions(Ge); TriggerAddCondition(Ge, hv[gX]); TriggerEvaluate(Ge)`（`8467-8545`）。
- 各技能进入特殊状态时把**碰撞条件**写入 `hv[单位]`（例：`hv=ni`(`CA`) 由 S010A(`RB`)/S010B(`IB`)/S012A(`AB`) 设置，
  `11877/11903/11962`；`hv=Ci`(`lb` Burnout) 在 `11263`）。
- 另有自定义伤害类型（`wR(gX,45)` / `TI(...)`），再次说明「伤害」是自建碰撞系统，不是 War3 武器攻击。

→ 所以我们把「技能状态交互」映射为**接触结算**是**正确基础**；此前把 `CA` 误写为「被攻击」已纠正。

**受此影响的交互清单（都应归入「接触」）**：
| 098c | 触发 | 我们 |
|---|---|---|
| `CA`（`ni`）`fr`/`Hr`/`Fr`+`gr` 分支 | 单位碰撞 | 招架已做 / `stealth_extra` 已做；`fr`/`Hr` 额外伤害分支未做（§2.2） |
| `bA`（破隐一击） | 由 `CA` 调用（碰撞） | `stealth_extra`（碰撞内） |
| `BA`（燃烧熄灭） | 由 `lb`/`CA`（碰撞） | Burnout（碰撞内） |
| `lb`（Burnout） | `hv=Ci`（碰撞） | 已实现 |
| 各技能 `hv=xx`（`9086/9462/10572/…`） | 单位碰撞的「命中回调」 | 以 `Projectile` 命中 / `resolve_player_collisions` 表达 |

> 排查结论：我们的「无普通攻击 + 接触/弹体命中」框架与 098c 一致；
> **未发现其它因“攻击”误设的地方**，唯一遗留是 `CA` 里 `fr`/`Hr` 的**接触额外伤害**（不影响播报）。

#### 0.6 我们 `resolve_player_collisions` 逐分支自查（vs 098c）

| 我们分支 | 098c 对应 | 状态 |
|---|---|---|
| 分离 + 动量交换 | `DA` 物理积分 | ✅ |
| 同队 Burnout（`burning`） | `lb`（`hv=Ci`） | ✅ |

| 风步接触招架（`contact_by_enemy`） | `CA` 的 `Fr/gr` 分支 | ✅ |
| —— | `CA` 的 `fr[nr]`/`Hr[nr]` 接触额外伤害 | ⬜ 未实现 |

**待核项（排查结论 — 2026-09-13）：**
1. **`stealth_extra` 部分错配（待修）**：重读 `CA` + `mI`/`FX`/`bA` 得到正确语义：
   - `mI(HI,JR)`：**HI=攻 / JR=受**（伤害由 `Gn[Vv[HI]]` 缩放）。故 `CA` 按**攻方 `nr`** 的状态分支。
   - `fr[nr]`（攻方带 S010A 冲锋）→ `mI(nr,Vr, 4.6+.8*wr)`（**×Gn**）命中；
     `bA()`：若 `xi>0`（范围精通）→ `SI(nr, 4.6+.8*wr, 1)`，即**以攻方为中心的 AoE**（走 `pI→mI→hI`，**吃 Gn**）。
   - `Hr[nr]`（攻方燃烧）→ `mI(..., 5+.4*Wr)`（×Gn）+ `FX(nr, 5+.4*Wr)` —— **`FX` 是自伤**（扣 `Fn[Vv[gX]]`，不乘 Gn，非“额外伤害”）+ `BA()`（燃烧结束）。
   - → 我们 `stealth_extra`：门控 `mastery[1]>0` ✓、值≈基础 ✓；但 **(a) 应是 AoE 而非单体、(b) 应吃 Gn**；
     之前“额外那笔不乘 Gn（FX）”是**误读**（FX 是自伤）。
2. **`CA` 的 `fr`/`Hr` 接触额外伤害**：`fr`→`4.6+.8*wr`；`Hr`→`5+.4*Wr`（×Gn）+ `FX` 自伤；我们**未实现**。
3. **敌人接触的 Burnout**（`CA` 的 `Hr[nr]` 分支：`FX` 自伤 + `BA` 结束）与我们已做的**同队** Burnout（`lb`）是**两条路径**，需确认是否都要。
4. **`kick` 伤害/击退公式**再对照（冲撞 `mI`）。
5. **注释过时**：`resolve_player_collisions` 的「挤压伤害」注释已删（已修）。

### 3.1 规格（按攻方状态分支）
