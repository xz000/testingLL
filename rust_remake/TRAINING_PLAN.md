# 单机试验场（训练场）完善规划

> 目标：把「单机试验场」从**一个不动靶子**升级成**可配置的训练场**：多靶子、会动、被打飞会走回来、
> 出界/岩浆等机制**真实生效可见**、有统计反馈，便于练连招/练走位/测技能。
> 本文先钉**现状事实**（含代码位置），再给**设计**与**分期计划**，最后是**需要你拍板的问题**。

---

## 0. 先纠正一个事实：试验场**不是完全不掉血**

| 伤害来源 | 试验场是否生效 | 证据 |
|---|---|---|
| 技能 / 弹体 / 爆炸 / 近战 | ✅ **照常扣血** | `damage_player_impl` 里**没有** `sandbox` 判断（`world.rs` 全文只有 3 处 sandbox 分支） |
| 玩家互撞 / 招架 | ✅ 生效 | 同上 |
| **出界 / 岩浆** | ❌ **被跳过** | `world.rs:796` `if !self.sandbox && p.pos.length() > self.arena_radius` |
| 缩圈 | ❌ 被跳过 | `world.rs:764` `if !self.sandbox { self.shrink_arena(dt) }` |
| 回合结束 | ❌ 永不 | `world.rs:3294` `round_over()` 遇 sandbox 直接 `false` |

所以：**你看到的"不扣血"应该是"出界/岩浆不掉血"**（这是刻意的沙盒豁免），技能伤害其实是扣的。
（如果实测发现技能也不掉血，那就是另一个 bug，需要单独复现；见 §6 验证清单。）

## 1. 现状盘点（试验场是怎么搭起来的）

| 项 | 现状 | 位置 |
|---|---|---|
| 入口 | `--solo` 命令行 / 主菜单第 1 项 | `client/src/main.rs` `parse_app_from_args` / `draw_menu` |
| 世界 | `World::new(2, SOLO_SEED)` → **只有 2 人**：`player0=你`，`player1=不动靶子`（注释原话） | `solo_world_and_meta()` |
| 沙盒标记 | `w.sandbox = true` | 同上 |
| 金钱 | `SOLO_STARTING_GOLD = 9999`（想买啥买啥） | 同上 |
| 剧本/档 | `MatchState::new(cfg, &[0], 8)` → **只给 player 0 建了 profile**（靶子没有档 → 不会施法/不会买东西） | 同上 |
| 靶子行为 | **完全不动**：Solo 走 `is_solo` 分支，非本机槽位一律 `PlayerInput::default()` | `update()` 内 `if is_solo { … }` |
| 已有 AI | **写了但从未启用**：`compute_inputs()` 里 `bot_targets`/`bot_rngs` **恒为空**（字段存在、注释自认"从未填充"），函数一进来就 early-return | `compute_inputs()`、字段 `bot_targets`/`bot_rngs` |
| 死亡后 | **不复活**：只有模式 2（死斗）4s / 模式 5（LMS）3s 会设 `respawn_at`；沙盒默认 `mode = 1` → **靶子一旦被打死就永久消失** | `record_death()` |
| 场地大小 | `Balance::start_radius_for(player_count)` → **人数越多圈越大**；障碍由 `_layout_obstacles(..., 1)` 生成 | `World::new` |
| 关键数值 | `max_hp=100`、`hp_regen=0.5/s`、出界/岩浆 `9/s`、玩家半径 `30` | `balance.rs` |
| 配置阶段 | Solo 有学习/配置阶段，按 `Space`/`P`/`回车` 手动开始对局 | `solo_config` 分支 |
| 可复用的表现层 | 伤害飘字、`combat_events`、`Player::total_damage`、`World::damage_matrix`、记分板 | `update_presentation` / `draw_scoreboard` |

## 2. 问题清单

- **P1 靶子只有一个**，且**不动** → 练不出走位/命中移动目标/击退方向。
- **P2 靶子死了就没了**（不复活）→ 打一会儿场地就空了，得重进。
- **P3 出界/岩浆机制在试验场被豁免** → "被打出界会怎样"完全看不到，也学不到"要回来"。
- **P4 AI 代码半成品**（`bot_targets`/`bot_rngs` 空转）→ 既是**死代码**，也是"看起来有 AI 其实没有"的误导。
- **P5 靶子没有 profile** → 无法让靶子"会反击"，也没有它的血条/伤害统计来源。
- **P6 圈随人数变大 / 障碍随机** → 训练场想要**稳定可复现**的场地（固定大小、可关障碍）。
- **P7 没有统计反馈**（总伤害/DPS/命中数）→ 练连招时看不出收益。
- **P8 没有"重置"入口** → 打得满地图弹幕/人都飞出去后没法一键回到初始状态。

---

## 3. 设计原则

1. **沙盒豁免要变成"开关"而不是写死**：把 `sandbox` 拆出细项（`sandbox_lava`、`sandbox_no_shrink`…），
   默认值保持"训练场该有的样子"，但每项都能开/关。
2. **AI 只在本地单机跑**：Solo 不联机、不进快照 → AI 生成放在客户端即可；
   但**必须确定性**（seeded `Rng`，复用现成 `bot_rngs`），这样能写单测、也可将来给 LAN host 用。
3. **默认值 = 现在能练到东西**：靶子 3 个、会漫游、出界会掉血 + 会自己走回来、死后 3s 复活。
4. **一切可关**：想回到"纯净测试台"（不动靶子、不掉血）也能一键切。
5. **可复现**：固定种子 / 固定场地大小 / 固定障碍（或可关），同一套输入每局一致。

## 4. 分期计划

### P0 —— 让训练场"真能练"（最小可用）

- **A. 多靶子**：靶子数量可配（1/2/3/5），`World::new(1 + n_bots, seed)`；沿环均匀分布。
  - 顺带把**场地大小固定**（不随人数放大），避免 5 个靶子时圈大到没边。
- **B. 靶子会动（复活既有 AI）**：填充 `bot_targets`/`bot_rngs`，并在 **Solo 分支**也给非本机槽喂 AI 输入
  （现在 Solo 直接跳过 AI）。行为分档：
  - `静止`（现状，作纯靶子）
  - `漫游`（在半径内随机游走，到点换目标）← **默认**
  - `走位`（被打飞后优先回场内、朝向远离弹幕）
- **C. 出界机制可见 + 会回来**：
  - 新增 `sandbox_lava: bool`（默认 **true**）：出界/岩浆**照常扣血**；
  - AI 增加**边界感知**：自身 `pos.length() > arena_radius * 0.95` 时目标点改为场地中心方向 → **被打出界会自己走回来**；
  - 玩家侧不变（玩家本来就该自己走回来）。
- **D. 靶子不消失**：
  - 方案①（默认）：沙盒内死亡 → `respawn_at = time + 3s`，复用 `revive_player`（满血、回随机点）；
  - 方案②（可切）："打不死"——HP ≤ 0 时立即回满并**计数"打爆一次"**，人不下场（适合练爆发连招）。

### P1 —— 好用

- **E. 训练场设置**（面板或快捷键菜单）：
  靶子数量 / 靶子行为 / 是否掉血 / 是否不死 / 是否缩圈 / 障碍开关 / 重置。
- **F. 一键重置**：满血 + 摆回出生环 + 清弹幕 + 清 DoT/状态（新增绑定动作 `SandboxReset`，默认 `F5`，
  避开施法键 `c r e d y t f g` 与镜头键；`F5` 目前空闲）。
- **G. 统计 HUD**：本轮总伤害 / 平均 DPS / 命中次数 / 最大单击 / 靶子血条（复用 `total_damage`、`damage_matrix`）。
- **H. （选做）靶子会反击**：给靶子建 profile（`MatchState::new(cfg, &[0,1,2…])`）+ 简单 AI 施法
  （朝玩家放一个已购技能，带冷却/命中率参数）→ 变成真正的"假人"。

### P2 —— 打磨

- **I. AI 难度**：反应延迟、瞄准误差、命中率、是否躲避（都走 seeded Rng，可复现）。
- **J. 巡逻靶**：沿固定路径移动的"木桩"，专门练预判。
- **K. 训练场专属小目标**：移动靶计时挑战（如 30s 内打爆 N 次）。
- **L. 代码收尾**：把 `compute_inputs` 的 AI 从"死代码"变成真路径（或删掉），补 `sandbox_*` 单测。

## 5. 影响面 / 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 改了 `sandbox` 本义影响现有单测 | `sandbox_never_ends_and_no_shrink`、`s018_sandbox_*` 等 20+ 测试依赖 `sandbox` | **不动 `sandbox` 语义**，另加 `sandbox_lava` 等细项，默认值让新测试显式设置 |
| AI 破坏确定性 | Solo 无同步，但将来若用于 LAN host 会分叉 | AI 只在**本地/房主**生成；用 seeded `Rng`；不允许 AI 进 `PlayerInput` 之外的状态 |
| 复活干扰统计 | `record_death` 会写 `eliminated_order`/`kills_this_round`，复活后记分板可能怪 | 沙盒内**跳过结算**（`settle_round` 已因不结束而不跑；确认 `take_kills` 也被清） |
| 多靶子把圈放大 | `start_radius_for(n)` 随人数变 | 训练场固定半径（覆盖该字段，或加 `arena_override`） |
| 键位冲突 | 重置键不能撞施法/镜头键 | 用空闲 `F5`，或并入「设置 → 按键设置」做第 20 个可绑动作 |
| 协议/快照 | 若新增 `World` 字段必须进 `world_ser` 且升 `PROTOCOL_VERSION` | 优先复用 `respawn_at` 等既有字段；确需新字段再升 21→22 |

## 6. 开工前先验证（避免计划建立在错误假设上）

1. 进 Solo，打靶子一发火球 → 看**漂字与靶子血条**是否掉（确认 §0 结论）。
2. 把靶子**推出圈外**（用击退/推挤）→ 确认它**不掉血**（现状豁免）。
3. 把靶子**打死** → 确认它**不再出现**。
4. 看看 Solo 里记分板/金币是否正常（沙盒不该计分）。

## 7. 需要你拍板（决定 P0 范围）

- **Q1 靶子数量**：默认几个？（建议 **3**；可 1/2/3/5 可选）
- **Q2 靶子行为**：默认哪档？（建议 **漫游**；另有 静止 / 走位 / 反击）
- **Q3 出界掉血**：默认 **开**（真实规则，能看到"出界很痛"）还是默认关？建议 **开**（可切）。
- **Q4 靶子生死**：默认 **死后 3s 复活**，还是 **打不死 + 打爆计数**？（建议复活；"打不死"作为可切选项）
- **Q5 玩家自己**：训练场要不要也**不死**（或"血量重置键"）？建议**保留真实掉血** + 一键重置，怕死就开不死开关。
- **Q6 入口形态**：训练场设置做成 **设置里的新页面**，还是 **Solo 内的快捷键菜单**（如 `F5` 打开）？
- **Q7 靶子会反击**（P1-H）要不要现在就排进 P0？建议**放 P1**，先把"能动的靶子"做出来。
