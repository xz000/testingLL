assets/fonts/cjk.ttf — 字体来源与许可
====================================

该文件是 **思源黑体 Noto Sans CJK SC** 的一个 **子集**，
原字体来自 Google 的 Noto CJK 项目（SIL Open Font License 1.1，OFL-1.1）。

裁剪方式：用 fontTools 的 pyftsubset 只保留了本项目源码中实际用到的大约 941 个字形
（中文 + 基础拉丁 + 常用标点），因此体积很小（约 168KB）。

SIL OFL 1.1 许可要点：
- 可以自由使用、修改、重分发（包括与软件一并分发），无需付费。
- 若你把修改后的字体重新分发，需改名为新字体名，且须保留 OFL 声明。
- 本文件为未修改的（子集化）Noto Sans CJK SC，可随项目分发。

完整 OFL 1.1 文本见：https://scripts.sil.org/OFL
